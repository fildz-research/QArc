# QArc: Lattice Structures

![qarc](https://github.com/user-attachments/assets/05f0b614-ae7d-49f9-939e-3a6b89466126)

QArc (QuasiArc) are arc-shaped cells designed for manufacturing lattice structures using fused deposition modeling (FDM) technology-based 3D printers.

| **Requirement** | **Required** | **Comment** |
